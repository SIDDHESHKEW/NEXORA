# 11. COMPLETE API CONTRACT

Base path `/api`, JSON, UTF-8, `Authorization: Bearer <jwt>` unless noted. Times are ISO-8601 UTC. Percentages are integers 0–100 (`pct`), estimates floats 0–1. Ids are integers. **Provenance fields:** every aggregate response carries `provenance: "LIVE" | "SEEDED" | "MIXED"` and (where useful) `seeded_note` so the UI can render `DEMONSTRATION DATA` chips.

## 11.0 Conventions
**Error envelope** `{ "error": { "code": "STRING", "message": "text", "details": [{"field":"x","issue":"y"}]?, "trace_id": "abc" } }` — codes in §9.8.
**Status enums** `LessonStatus = DRAFT|REVIEWED|APPROVED|PUBLISHED` · `MasteryStatus = STRONG|DEVELOPING|WEAK`.
**Shared types**
```ts
User        = { id, name, role: "STUDENT"|"TEACHER"|"ADMIN", student_id?, teacher_id?, section_id? }
Outcome     = { id, code: "LO4", statement, kind: "OUTCOME"|"PREREQUISITE", prerequisite_ids: number[] }
Block       = { id, seq, type: BlockType, title?, content: object, outcome_ids: number[], origin: "AI"|"EDITED", source_id? }
Lesson      = { id, topic_id, title, status: LessonStatus, generation_mode: "LIVE"|"FALLBACK",
                blocks: Block[], source: Source|null, unedited_ai_pct: number, approved_at?, published_at? }
Source      = { id, title, citation, approved: boolean }
StudentQuestion = { id, seq, stem, learning_outcome_id, options: {id,label,text}[] }   // never includes is_correct
MasteryItem = { outcome: Outcome, percent, estimate, status: MasteryStatus, evidence_count,
                prior_note: "Pre-class diagnostic (sample)", provenance: "MIXED" }
SessionState = { id, status: "LIVE"|"ENDED", version, lesson: { id, title, slides: Block[] },
                 section_id, current_slide_index, current_outcome_id|null,
                 quiz: { status: "NOT_STARTED"|"OPEN"|"CLOSED", submitted_count, total_participants },
                 active_poll: { id, status, question: StudentQuestion, counts?: Record<optionId,number> }|null,
                 active_prompt: { id, text }|null, participants_count, join_url }
```

**Generated lesson content schema (validator):** blocks in order `TITLE` · `OBJECTIVES` (one objective per LO) · `EXPLANATION` ×4 (one per LO, `outcome_ids=[loId]`) · `KEY_CONCEPTS` (list) · `EXAMPLE` (worked backpropagation example, tagged LO4) · `MISCONCEPTION` (tagged LO4; mentions "output error vs hidden-layer weight update") · `QUICK_CHECK` (question + answer, tagged LO4) · `SOURCE` (citation text must equal the approved source citation). Each block `content` is `{text}` or `{items:[…]}` or `{question,answer}`.
