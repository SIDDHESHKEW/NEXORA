1.  Project Overview and Goal
The objective is to build a polished, fully functional web-based demonstrator of an AI-Native University
Platform for Scope Global Skills University (SGSU). The team has two days to build the working project.
Scoping decision. The 89 proposed features will not be implemented individually. Instead, the team
builds one complete, closed intelligence loop that makes the product feel like a complete university AI
ecosystem. The demonstrator must not look like an incomplete prototype: it must look like a finished,
professional product.
The product presents four connected user-facing layers powered by one shared Platform Core. The central
story of the demo is:
TEACH > ASSESS > UNDERSTAND > PERSONALIZE > IMPROVE > INFORM UNIVERSITY
The system must demonstrate that the same learning evidence generated by a student in the classroom can
immediately influence:

the student's personalized learning,

the teacher's next action, and

the university administrator's academic insight.
This is the most important concept of the entire project.
2.  Product Structure and Architecture
One web application containing five components: the Platform Core and four user-facing layers.
Component
Role
A. Platform Core
Shared backend: curriculum, content, assessment, evidence, mastery,
recommendations, AI, governance
B. AI Teacher Studio
Teacher layer: create lessons, review, approve, publish, view class insight, receive
re-teach recommendations
C. AI Smart Classroom
Live classroom presentation mode with polls, questions and exit quiz
D. Student Intelligence
Personalized dashboard, learning gap, practice, AI tutor, skill passport
E. University Intelligence
Aggregated academic intelligence, recurring gaps, governance
The four user-facing layers must not behave like four disconnected applications. They use the same underlying
course, topic, learning outcomes, students, questions, responses and mastery data.
